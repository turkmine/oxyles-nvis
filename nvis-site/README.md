# NVIS — страница загрузки

Одностраничный сайт для скачивания **Nvis by Oxyles** — программы для Windows,
которая регулирует гамму экрана. Та же чёрно-белая манга-палитра и те же
переключатели, что на био-сайте, но страница заточена под одну задачу:
объяснить, что это, и отдать файл.

Ни одного стороннего запроса: ни CDN, ни веб-шрифтов, ни аналитики, ни картинок
из сети. Установщик отдаётся прямо с этого домена.

CSS и инлайновый SVG. Установщик (57,4 МБ) в эти 109 КБ не входит.

## ⚠️ Что заменить перед публикацией

### 1. Адрес сайта

Предполагается `https://nvis-site.turkmine3456.workers.dev/` (по аналогии с
био-сайтом). Если воркер будет называться иначе — поменяй:

| Файл | Что искать |
|---|---|
| `index.html` | `rel="canonical"`, `og:url`, `og:image`, `downloadUrl` в JSON-LD |
| `sitemap.xml` | `<loc>` |
| `robots.txt` | строка `Sitemap:` |
| `deploy/nginx.conf` | `server_name` и пути к сертификату |

### 2. Где лежит установщик

Установщик весит **57,4 МБ**, а Cloudflare Workers и Pages не принимают файл
больше **25 МиБ** — поэтому `.msi` лежит в **GitHub Releases**, а папка
`downloads/` исключена из выкладки через `.assetsignore`.

Адрес установщика задан в двух местах, и они должны совпадать:

| Файл | Что искать |
|---|---|
| `js/config.js` | `product.downloadUrl` |
| `index.html` | `href` у `.dl__btn` и `downloadUrl` в JSON-LD |

```js
downloadUrl: 'https://github.com/turkmine/oxyles-nvis/releases/download/1.0.0/Nvis-Setup-1.0.0.msi',
```

> ⚠️ **Репозиторий должен быть публичным.** Пока он приватный, GitHub отдаёт файл
> только после входа в аккаунт и посетитель сайта вместо установщика получит
> страницу логина. Сделать публичным: **Settings → Danger Zone → Change
> visibility → Make public**.

> Тег `1.0.0` — без буквы `v`. Адрес чувствителен к этому: в нём ровно то,
> что ты назвал при создании релиза.

Атрибута `download` у кнопки нет намеренно: браузер игнорирует его для ссылок
на чужой домен, а имя файла и так задаёт GitHub заголовком
`Content-Disposition`.

При выпуске новой версии: создай тег `v1.0.1`, положи новый `.msi` в Releases,
затем обнови `product.version`, `product.fileName`, `product.sizeLabel`,
`downloadUrl` в обоих файлах и подпись в кнопке.

### 3. Раскладка в репозитории

Сайт лежит в подпапке `nvis-site/`, поэтому конфиг смотрит именно туда:

```jsonc
"assets": { "directory": "./nvis-site/" }
```

`.assetsignore` лежит **в папке со статикой**, то есть в `nvis-site/` —
wrangler ищет его именно там, это требование платформы.

Ошибка `Could not detect a directory containing static files` означает ровно
одно: путь в `directory` не указывает туда, где лежит `index.html`.

## Как поменять содержимое

Всё правится в **`js/config.js`**. HTML при этом трогать не нужно, но если
JavaScript выключен, страница покажет то, что вписано прямо в разметку, —
поэтому при смене версии или ссылок править и `index.html`.

| Что | Где в config |
|---|---|
| Название в шапке | `product.brand`, `product.name` |
| Строки под именем | `product.tagline` (массив, между ними ставятся точки) |
| Версия, система, размер, имя файла | `product.version`, `platform`, `sizeLabel`, `fileName` |
| Текст под кнопкой | `product.downloadNote` |
| Сайт разработчика | `product.links.home` |
| Telegram / Discord / Steam | `product.links` |

> **Про ссылку на скачивание.** Она лежит в `index.html` — в атрибуте `href`
> и `download` кнопки `.dl__btn`. В `config.js` лежит только подпись
> (`fileName`), потому что сама ссылка должна работать и без JS.
> При выпуске новой версии: положи новый `.msi` в `downloads/`, поменяй
> `href`, `download`, `product.version`, `product.fileName`, `product.sizeLabel`,
> подпись в кнопке и `downloadUrl` в JSON-LD.

Тексты «Что это», «Что умеет», «Шкала гаммы», «Горячие клавиши», «Обо мне»
лежат прямо в `index.html` — там они читаются как обычный документ и видны
поисковикам.

Если оставить `url` в `links` пустой строкой, значок намеренно превратится
в `<span>` с подписью «ссылка не задана» — без битого якоря для краулера.

## Темы и эффекты

**Кнопка `黒 / 白`** в шапке переключает темы:

- `ink` — инверс: светлые чернила на почти чёрном фоне
- `paper` — бумага: чёрные чернила на тёплом белом

Выбор сохраняется в `localStorage` (`nvis.theme`). Пока пользователь ничего
не выбирал, сайт следует системной теме и продолжает следовать ей при её смене.
Тема ставится скриптом `boot-theme.js` **до** первой отрисовки, поэтому при
перезагрузке на тёмной теме нет вспышки белого.

**Кнопка `✦ Эффекты`** отключает линии скорости, скринтон и частицы на canvas.
Состояние тоже запоминается (`nvis.fx`).

При `prefers-reduced-motion: reduce` всё это отключается само, независимо от кнопок.

## Про безопасность

| Мера | Как сделано |
|---|---|
| CSP | `default-src 'none'` + только `'self'`. В `index.html` нет ни одного инлайнового `<script>` и `<style>`, `on*`-обработчиков и `style=""` |
| Где отдаётся CSP | В заголовках сервера, **не** в `<meta http-equiv>`: в `meta` не работает `frame-ancestors`, и браузер применяет `meta`-CSP к служебным запросам вроде `robots.txt` |
| Загрузка ресурсов | `connect-src 'none'` — страница не может никуда «позвонить»: ни аналитики, ни счётчиков, ни скрытых запросов |
| Установщик | Отдаётся с того же домена, `Content-Type: application/x-msi`, кэш на неделю. Внешних ссылок на скачивание нет |
| Внешние ссылки | У всех `rel="noopener noreferrer"`, `target="_blank"` |
| Хранилище | `localStorage` только на чтение/запись своих ключей, всё в `try/catch` — не падает в приватном режиме |
| Инъекции | Пользовательский ввод нигде не используется; тексты ставятся через `textContent`, не через `innerHTML` |
| Кадры | `frame-ancestors 'none'` + `X-Frame-Options: DENY` |

## Запуск локально

Нужен любой статический сервер — сборка не требуется.

```bash
# Python
python -m http.server 8000

# или Node
npx serve .
```

Открыть `http://localhost:8000`.

## Доступность

- Скип-ссылка «Перейти к содержимому»
- `aria-pressed` на переключателях, `aria-current` на активном разделе
- Имя кнопки начинается с видимого текста (иначе скринридер читает одно, а написано другое)
- Значок соцсети без ссылки — это `<span>`, а не `<a>` без `href`: битых якорей для краулеров нет
- Макет окна программы помечен `aria-hidden` — это иллюстрация, а не элемент управления
- Вся навигация и все значки — обычные ссылки и кнопки, работают без JS
- `prefers-reduced-motion` и `prefers-contrast` учитываются
- Стиль печати: фон и макет окна убраны, ссылки раскрываются в скобки

## Чего нет и почему

- **Видеофона и музыки.** Фон сделан на CSS, поэтому страница весит килограммы,
  а не десятки мегабайт, и не грузит трафик на мобильных.
- **Защиты от копирования** (`devtools-detect`, обфускация). Весь код открытый
  и это осознанно: страницу всё равно можно сохранить через «Просмотреть
  исходный код», а ломая доступ, можно навредить себе в отладке.
- **Счётчика скачиваний.** Он бы отправлял данные на сторону — а здесь
  заявлено, что страница никуда не ходит. Логи хостинга и так скажут, сколько
  раз файл забрали.
